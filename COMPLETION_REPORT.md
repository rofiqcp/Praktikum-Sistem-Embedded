## 🔧 TECHNICAL SPECIFICATIONS

### Development Environment:
- **IDE:** PlatformIO (VSCode extension)
- **STM32 Framework:** STM32Cube HAL
- **ESP32 Framework:** Espressif ESP-IDF
- **Version Control:** Git-ready structure

### Target Hardware:
**STM32:**
- Primary: STM32F103 Blue Pill
- Also covers: STM32F4, STM32H7 features
- Programmer: ST-LINK V2

**ESP32:**
- Primary: ESP32 DevKit v1 (ESP32-WROOM-32)
- Also covers: ESP32-S2, ESP32-C3 features
- Programming: USB (built-in)

### Peripheral Coverage:
```
✅ GPIO (Input/Output/Interrupt)

✅ ADC (12-bit, 16-bit on STM32H7)

✅ I²C (up to 4 on STM32, 2 on ESP32)
✅ SPI (up to 6 on STM32, 4 on ESP32)
```

## 📝 FINAL NOTES

This documentation package represents a comprehensive embedded systems curriculum designed for Indonesian-speaking students and professionals. The material covers both STM32 (ARM Cortex-M) and ESP32 (Xtensa) platforms in a parallel comparison approach, allowing learners to understand:

1. **Common concepts** that apply to all microcontrollers
2. **Platform-specific features** that make each unique
3. **When to use which** platform for real projects
4. **Practical skills** ready for industry

The curriculum is designed to be:
- **Practical:** 350+ working examples
